Ostrzeżenie systemu Windows

Podczas pobierania lub uruchamiania SZOPERO Windows może wyświetlić ostrzeżenie Microsoft Defender SmartScreen. Może się tak zdarzyć, ponieważ aplikacja jest niezależnym projektem i nie ma jeszcze szerokiej reputacji w systemie Windows.

Samo ostrzeżenie nie oznacza, że aplikacja jest złośliwa, ale nie jest też dowodem jej bezpieczeństwa. Sprawdź źródło pliku i pobieraj SZOPERO wyłącznie z oficjalnego repozytorium.
